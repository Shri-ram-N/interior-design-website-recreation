# Interior Design Website Recreation

A responsive interior design website recreated using HTML and CSS.

## 🌐 Live Demo

https://shri-ram-n.github.io/interior-design-website-recreation/

## 📌 About the Project

This project is a recreation of an interior design website, developed as a front-end practice project.

The website uses a clean layout, interior design imagery, navigation elements, and responsive styling to create a modern interior-design-focused experience.

## 🛠️ Technologies Used

- CSS3
- Git
- GitHub
- GitHub Pages
